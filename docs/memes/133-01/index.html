El contexto

La edición imaginaba tres futuros para 2030: una IA que apenas mejora, otra que avanza de forma sostenida y otra que progresa muy deprisa. El responsable político duda entre prepararse para poco cambio o para una transformación enorme. Ninguna de las dos opciones ofrece la seguridad de acertar.
