El contexto

La «Constitución de Claude» es el conjunto de principios con el que Anthropic orienta el comportamiento de su IA. La escala pregunta quién debe fijar y vigilar las reglas: primero aparecen las empresas y después la participación democrática. El último nivel reclama instituciones capaces de supervisar sistemas cada vez más potentes.
